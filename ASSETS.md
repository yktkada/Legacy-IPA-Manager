# Assets

## Application icons

The following custom application icons were created by the project owner using
Gemini and ChatGPT image generation:

- `IdeviceGui/prototype/IdeviceGui/app.ico` (S-tier icon for desktop, taskbar, and Alt+Tab)
- `IdeviceGui/prototype/IdeviceIndex/app.ico` (S-tier icon for `IdeviceIndex`)
- `IdeviceGui/prototype/IdeviceGui/icon_large.png` (L-tier icon embedded for Settings -> About)
- `IdeviceGui/prototype/IdeviceIndex/icon_large.png` (L-tier icon embedded for `IdeviceIndex` Settings)
- `assets/manager-icon.png` (L-tier icon displayed in GitHub README and User Guides)
- `assets/index-icon.png` (L-tier icon displayed in `IdeviceIndex` documentation and User Guides)

No third-party brand logo or commercial icon asset is included. These assets are
